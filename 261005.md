## Theorie
**Kurze Zusammenfassung:**
Wenn man in Linux öfter die gleichen Aufgaben machen muss, kann man das mit **Bash Scripting** ziemlich leicht automatisieren. Im Prinzip schreibt man einfach Befehle, die man sonst mühsam einzeln eintippen müsste, in eine Datei und führt sie zusammen aus. Richtig praktisch wird das Ganze aber erst durch Schleifen (wie `for` oder `while`) und `if`-Bedingungen, weil das Skript dann selber logische Entscheidungen treffen kann. Man kann dem Skript beim Starten auch Argumente (also Parameter) mitgeben, wodurch es flexibel mit verschiedenen Daten arbeitet, ohne das man den Code jedes mal ändern muss.

**Wichtigsten Bausteine:**
- `for i in {1..42}`: Eine ganz normale Schleife die einfach von einem Startwert bis zum Endwert hochzählt (in dem Fall von 1 bis 42) und den Wert in `i` speichert.
- `$@`: Das ist eine spezielle Variable, die für alle Argumente steht, die dem Skript beim Aufrufen übergeben wurden. Das braucht man vor allem dann, wenn man vorher noch gar nicht weiß wie viele Zahlen der User überhaupt eingibt.
- `(( ... ))`: Damit kann man in der Bash mathematische Berechnungen machen. Das wird zum Beispiel für Modulo-Rechnungen (`%`) oder Vergleiche benutzt und ist ziemlich schnell.
- `cat "datei" | xargs`: Ein guter Trick, um den Inhalt aus einer Datei einzulesen. Durch das `xargs` ist es komplett egal, ob die Zahlen durch Leerzeichen oder neue Zeilen getrennt sind – sie werden einfach nacheinander in die Schleife geworfen.

## 1. Übung (Even/Odd)
Create a simple script which will print the numbers 1–42 (each on a separate line) and whether they are even or odd.

**Regeln:**
  - Zahlen von 1 bis 42 durchlaufen
  - Jede Zahl auf einer neuen Zeile ausgeben
  - Prüfen, ob die Zahl gerade (even) oder ungerade (odd) ist

---
### Lösung:

```sh
#!/bin/bash

# Schleife von 1 bis 42 durchlaufen
for i in {1..42}
do
    # Mit Modulo prüfen ob der Rest bei Division durch 2 gleich 0 ist
    if (( i % 2 == 0 )); then
        echo "$i ist even"
    else
        echo "$i ist odd"
    fi
done
```

## 2. Übung (Summe und Maximum)
Schreibe ein bash Skript das eine beliebige menge von positiven Zahlen als Argumente aus der Kommandozeile übernimmt. Es soll die Summe und die größte Zahl ausgegeben werden. Hinweis: Verwende $@.
**Regeln:**
- Beliebig viele Argumente erlauben beim Aufruf
- Summe von allen Zahlen berechnen
- Die größte Zahl (Maximum) rausfinden
### Lösung:

```sh

#!/bin/bash

summe=0
max=0

# Schleife geht durch alle übergebenen Argumente durch
for zahl in "$@"
do
    # 1. Zahl zur aktuellen Summe dazuaddieren
    (( summe += zahl ))

    # 2. Prüfen ob die aktuelle Zahl größer als das alte Max ist
    if (( zahl > max )); then
        max=$zahl
    fi
done

echo "Summe: $summe"
echo "Größte Zahl: $max"
```

- summe=0 und max=0 setzt die Variablen am Anfang mal auf Null (da wir ja sowieso nur positive Zahlen bekommen).
- for zahl in `"$@"` ist hier der wichtigste Punkt: Das $@ schnappt sich alle Argumente die beim Skript-Aufruf mitgegeben wurden und geht sie der Reihe nach durch.
- `(( summe += zahl ))`ist einfach die Kurzschreibweise um die aktuelle Zahl auf die Summe draufzurechnen
- if (( zahl > max )) vergleicht die Zahl mit dem bisherigen Maximum. Wenn die neue Zahl größer ist, wird der Wert in max überschrieben.
